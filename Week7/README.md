# UCS301 Data Structures — Lab Assignment 7 (Sorting)

Each question is implemented in its own .cpp file. All files compile
standalone and include a main() that runs the examples from the
assignment sheet.

| File | Question |
|---|---|
| 1a_selection_sort.cpp | Q1a — Selection Sort |
| 1b_insertion_sort.cpp | Q1b — Insertion Sort |
| 1c_bubble_sort.cpp | Q1c — Bubble Sort |
| 1d_merge_sort.cpp | Q1d — Merge Sort |
| 1e_quick_sort.cpp | Q1e — Quick Sort |
| 2_improved_selection_sort.cpp | Q2 — Improved selection sort (min + max per pass) |
| additional_1_majority_element.cpp | Additional Q1 — Majority Element |
| additional_2_top_k_frequent.cpp | Additional Q2 — Top K Frequent in Array |
| additional_3_maximum_sum_combination.cpp | Additional Q3 — Maximum Sum Combination |
| additional_4_sort_even_odd_placed.cpp | Additional Q4 — Sort even-placed increasing / odd-placed decreasing |
| additional_5_maximum_ice_cream_bars.cpp | Additional Q5 — Maximum Ice Cream Bars (counting sort) |

## Compile & run any file
```
g++ -std=c++17 -o out <filename>.cpp
./out
```

All 11 programs were compiled and run — their output matches the
sample outputs given in the assignment PDF.
